# 🎨 Paint Application

An extensible and interactive **Paint Application** built with **Java** and **JavaFX**, designed to support modular feature integration and AI-powered file manipulation. This project re-architects traditional paint software through object-oriented design principles, pattern-based development, and collaborative agile workflows.

---

## 🚀 Overview

The Paint Application enables users to draw, edit, and save graphics interactively while maintaining a scalable, maintainable architecture. Core enhancements include the addition of **Polyline tools**, **Save/Load functionality**, and **AI-driven file modifications** via **Ollama3**, all developed under a modular and extensible design framework.

---

## 🧠 Key Features

- **Modular Architecture:** Refactored using clean code principles for easy feature extension  
- **Advanced Drawing Tools:** Polyline, Line, Rectangle, and Freehand brush tools  
- **AI-Assisted File Handling:** Integrated Ollama3 for automated file modification suggestions  
- **Save/Load System:** Reliable serialization for persistent user sessions  
- **Regex Parsers & State Machines:** Ensures robust command interpretation and error handling  
- **Pattern-Driven Design:** Incorporates MVC, Factory, Command, and Strategy patterns for clarity and scalability  

---
